# Astro Content Guide

A searchable guide to Astro's TV channels in Malaysia, pulled live from Astro's public content API.

**Live:** https://astro-content-guide.netlify.app/

## Features

- Search by channel name
- Filter by category (Movies, Sports, Kids, News and more) and language (Malay, Chinese, Indian and others)
- HD-only toggle
- A-Z / Z-A sorting
- Favourites, saved in local storage
- Light/dark mode

## Built with

React 18, Chakra UI, React Router, Axios

## Run it locally

```bash
npm install
npm start
```
